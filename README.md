# QuickBill

> A lightweight, mobile-first POS and thermal receipt web app built for international merchants.

## Features
* **Multi-Language Support (i18n):** Instant UI toggles between English, Marathi, Hindi, Spanish, and Arabic.
* **Dynamic Payments:** Real-time UPI and custom QR code generation on checkout.
* **Thermal Receipts:** Clean 80mm dual-language receipt layout for physical printing or PDF downloads.
* **Offline Storage:** Local caching via `localStorage` for continuous operation during network drops.

## Tech Stack
* React / HTML5 / JavaScript (ES6+)
* Tailwind CSS
* Custom Lightweight i18n Context

## Quick Start
```bash
git clone [https://github.com/FreakNgo/QuickBill.git](https://github.com/FreakNgo/QuickBill.git)
cd QuickBill
npm install
